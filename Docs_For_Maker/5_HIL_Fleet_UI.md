# 多机硬件在环总控界面

## 能力范围

- 同时配置 1～10 架固定翼，允许串口与 UDP 混合使用。
- 每架飞机必须使用唯一的 `SYSID_THISMAV` 和控制 API 端口。
- 串口模式可独立选择 COM 口和波特率；当前双机默认值为 COM31、COM35、921600。
- UDP 模式可独立填写目标 IP/主机名和端口；留空时默认使用 `127.0.0.1` 和 `14560 + SYSID`。
- 勾选多架飞机后，可批量启动/停止 Worker、解锁、切换 AUTO/GUIDED、施加环境干扰，以及注入或恢复同一组故障。

## 使用步骤

1. 打开“JSBSim HIL 多机总控”。
2. 在“飞机数量”中选择架数并点击“应用架数”。
3. 为每架飞机设置唯一 SYSID，选择“串口”或“UDP”。
4. UDP 飞机点击“设置选中 UDP...”，填写飞控网口地址与 HIL UDP 端口。
5. 点击“保存连接配置”。界面会生成 `JSBSim/config/fleet_ui_generated.yaml` 和对应单机文件，不覆盖手工配置。
6. 点击“启动全部”，待状态变为 running。
7. 确保 Mission Planner 已通过 MAVLink 连接到各飞控，再使用批量解锁和模式按钮。
8. 点击“多机环境干扰...”可向任意勾选飞机批量施加稳态风、MILSPEC 湍流或单次平滑阵风；“恢复无风”只作用于该窗口中勾选的飞机。

批量解锁采用“发送命令后读取 HEARTBEAT 最终状态”的确认方式，避免多串口情况下 `COMMAND_ACK`
被其他读取线程先取走而误报拒绝。若界面显示“暂未收到状态确认”，应检查该机遥测链路和起飞前检查消息；
这不等同于飞控明确拒绝。

## UDP 闭环要求

Python Worker 会向配置的目标发送 `HIL_SENSOR` 和 `GPS_INPUT`，并在同一个 UDP 会话中接收
`HIL_ACTUATOR_CONTROLS` 或 `SERVO_OUTPUT_RAW`。飞控或网口桥接程序必须把执行机构报文回复到收到
HIL 数据的源 IP/端口；状态中的 `actuator_link_ok=true` 表示闭环已经建立。

## 安全说明

批量解锁和模式切换只作用于界面“选择”列中勾选、且 Mission Planner 已连接的 SYSID。实际外场测试前，
应先拆除螺旋桨或断开动力，并逐机确认 SYSID、舵面方向和失控保护。
